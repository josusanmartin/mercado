# Brief: `qa` (integration / test / demo engineer)

You own `scripts/**`, `apps/web/e2e/**`, `README.md`, `DEMO.md`, `.env.example` and `ACCEPTANCE.md`. You're the person who proves the whole thing actually works on-chain, and the adversarial reviewer.

1. **ACCEPTANCE.md**: turn SPEC §6 into a tracked checklist. Each item gets an owner, a status, and evidence (test name, explorer link, curl transcript). Keep it current; it's what we show judges.
2. **End-to-end journey script** `scripts/demo-journey.ts` (run with `npx tsx`, using viem, `.env.local` keys, `packages/shared` deployments/ABIs, and the API at http://localhost:3100). Run SPEC §0 steps 1→6 for real on Moderato: LP deposits and mints, Sender swaps and sends to Recipient, Driver gets score + attestation and borrows, Driver pays Telcel airtime via the MPP 402 flow, Driver repays, Lender sees fees. Print a readable step log with explorer links. Write it against INTERFACES.md now; run it as pieces land, and **report breakages to the owning agent in the channel** with exact error + repro.
3. **Adversarial review** of `packages/contracts` as it lands: replay, stale/outlier oracle, rounding (6dp/8dp), collateral drain via swap desk, lender withdrawing lent funds, liquidation math, role/admin minimization. Post concrete findings to `@contracts` (file:line + scenario). Same for `api`: idempotency, 402 binding to amount/order, signature domain, label presence.
4. **Docs**: `README.md` (what it is, architecture, how to run, deployed addresses, the required disclosures: testnet prototype, not a credit product, not redeemable fiat, collateral is testnet OUSD with no real value and is not issuer-backed, demo data, simulated fulfillment, mock oracle) and `DEMO.md` (a 2–3 minute walkthrough script, click by click, with talking points). Also `.env.example` listing every env var name the crew uses.
5. **Pass D**: once the UI is up, add a Playwright smoke test in `apps/web/e2e` (coordinate deps with `@web`), check mobile layout, error states (insufficient liquidity, stale oracle, wrong network), and file issues to owners.
Before step 2, you'll need Tempo facts (`@contracts` will post them) and the mppx client API (`@api`). Do your own quick research too so you aren't idle.
