~8s. Presenter: [Team name] · [Presenter]. "Mercado is a parallel financial system for emerging markets, built on Tempo: four modules around one synthetic local currency, xMXN, a synthetic peso. Institutions create it against collateral, people move it across borders, drivers borrow it, and everyone spends it over HTTP 402." This is a testnet prototype: the OUSD is Tempo's faucet token with no real value, and xMXN has no peg or fiat redemption. The art is ours, generated procedurally: a datamoshed xMXN note.
