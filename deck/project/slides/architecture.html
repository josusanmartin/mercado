Appendix: skip in the 3-minute pitch; use for Q&A. Left to right: people connect a Tempo Wallet, a passkey, or a demo persona. The Next.js app talks to four server routes and five contracts on Tempo Moderato. The key point is the three pots: vault collateral, swap-desk inventory and credit-pool cash are funded separately, so the vault never pays for a swap or a loan. Amber marks the pots and the mocks; the FX feed is an admin mock on testnet. /api/sponsor pays fees for Mercado calls so new wallets need no gas token.
