~8s. The same 402 rail works between machines. A brand-new bot wallet, funded from the faucet with no API key, account or signup, asks Mercado's score API for an underwriting report. It gets a 402 for 2 xMXN, pays on Tempo with a transfer bound to the challenge, and gets the report back with a Payment-Receipt. The report is the illustrative score on Demo Uber Data, and it never includes a borrow attestation: only the borrower's own session gets one. Live on Moderato; transcript in scripts/evidence/underwriter-agent.txt.
