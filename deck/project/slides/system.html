03

~15s. The whole system on one slide. Create: institutions lock collateral and mint xMXN; the collateral can be yield-bearing (staked OUSD, tokenized T-bills) so it keeps earning inside its own token while locked. Today the OUSD vault is live on testnet; staked OUSD and T-bills are demo tokens with admin-set yield and prices, being built as v2 alongside v1, with no claim of real T-bill backing or real yield. Move: the vault becomes the exchange, so OUSD in mints xMXN and xMXN out burns it and redeems OUSD, priced off the oracle; that vAMM is in progress, and today's live path is the separately funded swap desk. Lend: driver advances from the lender pool, live. Spend: HTTP 402 payments for bills and agent APIs, live. Testnet prototype: no peg, no fiat redemption, no real yield.
