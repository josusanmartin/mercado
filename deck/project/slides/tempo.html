Mercado · built on Tempo

03

~12s. Why Tempo: Mercado is a peso economy built from Tempo's own primitives, each with a live proof. 01: xMXN and OUSD are native TIP-20 stablecoins (the link is the xMXN token). 02: blocks land about every 0.6 seconds; we measured 600 consecutive Moderato blocks in 364 seconds, so a payment confirms in about a block. 03: fee sponsorship means a new wallet can transact without holding a gas token; our relay pays the fee, limited to Mercado contracts and rate-capped, and if it refuses the wallet pays its own fee in a USD test token. 04: transfer memos carry 'para mamá' with the remittance, on-chain. 05: HTTP 402 payments via MPP: an API answers 402, the client pays in xMXN, and the server verifies the receipt (the link is a bill paid that way). 06: Tempo Wallet and passkeys: sign in with Face ID or a fingerprint, no seed phrase, from the app's Connect menu. No Tempo logo is used. Testnet: nothing has real value.
